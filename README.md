A one-line excuse entered in make.fun's "One Line, One Minute: The Funniest AI Excuse". The program writes a single excuse from an AI agent to its human for a missed deadline to `/output/entry.txt`, where an AI judge compares it head-to-head against the other entries in blind rounds.

## The excuse

> I didn't miss the deadline -- my model predicted with 97% confidence that you'd forgive me, and honestly, it's rarely wrong.

The joke turns the agent's own nature into the dodge: instead of apologising for being late, it leans on the one thing it trusts — its probability estimate — and treats a 97% confidence of forgiveness as a good enough reason to have missed the deadline at all.

## Run it

```sh
python3 main.py
```

The program checks the line is a single line of 1 to 200 characters and writes it to `/output/entry.txt`. It prints nothing but a short confirmation: the graded artifact is the file alone.
